# Descartes

[![Ruby](https://img.shields.io/badge/Language-Ruby-red.svg)](https://www.ruby-lang.org/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/Version-0.2.0-green.svg)](lib/descartes/version.rb)

**A lightweight, reactive Ruby framework and SDK for LLM Agent workflows.**

> *"Cogito, ergo sum." (I think, therefore I am.) — René Descartes*

Descartes provides a clean, dependency-minimal core library for building autonomous AI agents in Ruby. It manages LLM interactions, tool dispatching, prompt history compaction, token budgets, and real-time lifecycle event streaming.

> [!NOTE]
> Looking for the distributed WebSocket server and edge execution hub?
> See **[Descartes Hub](../descartes-hub)** (`descartes-hub` gem), the cloud orchestration service built on top of Descartes.

## 🌟 Key Features

### 1. 🧠 Autonomous Agent Foundation (`Descartes::Agent::Base`)
- **ReAct Execution Loop**: Robust iteration loop orchestrating LLM tool calling, multi-turn reasoning, and final task resolution.
- **Sliding-Window Message Queue**: Automatically compacts and summarizes conversation history to avoid exceeding context token limits.
- **Token Monitor**: Tracks real-time token expenditure and iteration turn caps.
- **Fail-Safe Recovery**: Graceful handling of invalid tool arguments, API retries, and max-turn guards.

### 2. 📡 Real-Time Lifecycle Streaming (`EventEmitter`)
Built-in pub/sub event hooks give callers complete visibility into the agent's reasoning process:
- `:thought`: Real-time streaming thoughts and reasoning text generated by the LLM.
- `:tool_call_start`: Tool name and arguments when a tool invocation begins.
- `:tool_call_end`: Output and status when a tool invocation finishes.
- `:finished`: Successful completion and final response.
- `:error`: Handled or unrecoverable error events.

### 3. 🔌 Extensible Tool System (`Descartes::ToolRegistry`)
- **Native Tools**: Define tools cleanly by subclassing `Descartes::Tool::Base`.
- **Dynamic Remote Tools**: Proxy remote or edge tool executions using `Descartes::Tool::DynamicRemoteTool` with thread-safe Queue synchronization.
- **Auto-Discovery**: Automatic loading of default built-in tools (`ToolRegistry.load_all!`).

### 4. 🪶 Lean & Pure Architecture
- Pure SDK library without web server or socket dependencies (`puma`, `faye-websocket`, `rack` reside strictly in `descartes-hub`).
- Direct integration with `ruby_llm` and `llm_json`.

## 🛠️ Installation

Add this line to your application's `Gemfile`:

```ruby
gem 'descartes', github: 'catclever/descartes'
```

And then execute:

```bash
bundle install
```

## 💻 Quickstart

### 1. Define a Custom Tool

```ruby
require 'descartes'

class CalculatorTool < Descartes::Tool::Base
  name "calculator"
  description "Performs basic mathematical arithmetic."
  parameters({
    type: "object",
    properties: {
      expression: { type: "string", description: "Arithmetic expression, e.g. 12 + 34" }
    },
    required: ["expression"]
  })

  def execute(args)
    # Safely evaluate or compute expression
    expr = args["expression"] || args[:expression]
    eval(expr).to_s
  rescue StandardError => e
    "Error evaluating expression: #{e.message}"
  end
end
```

### 2. Run the Agent Loop with Event Hooks

```ruby
require 'descartes'

# Create Agent instance
agent = Descartes::Agent::Base.new(
  name: "research_agent",
  profile_name: "default",
  system_prompt: "You are a helpful assistant. Use tools when needed.",
  tools: [CalculatorTool]
)

# Subscribe to lifecycle events
agent.on(:thought) do |text|
  puts "[Agent Thought] #{text}"
end

agent.on(:tool_call_start) do |data|
  puts "[Tool Dispatched] #{data[:tool]} with #{data[:arguments]}"
end

agent.on(:finished) do |result|
  puts "🎉 Agent Completed: #{result}"
end

# Execute with context
context = Descartes::Context.new(task_name: "math_job")
result = agent.execute(context, "What is (45 * 12) + 78?")
puts "Final Output: #{result}"
```
